Assignment 1 – What Happens Between Typing a URL and Seeing the Page?


ANS-1. When a user types a URL into a browser and presses Enter, several steps take place before the webpage appears.

Steps Involved
URL Entry: The user enters a website URL into the browser.
Cache Check: The browser checks for previously stored resources.
DNS Lookup: DNS translates the domain name into an IP address.
Connection Establishment: The browser establishes a connection with the web server. HTTPS uses encryption through TLS.
HTTP Request: The browser sends a request to the server for the webpage.
Server Response: The server returns an HTTP response containing a status code, headers, and content.
HTML Parsing: The browser parses HTML and constructs the DOM.
Resource Loading: The browser requests resources such as CSS, JavaScript, images, and fonts.
CSS Processing: The browser parses CSS to determine how the webpage should look.
Rendering: The browser calculates layout, paints the content, and displays the webpage.
JavaScript Execution: JavaScript may modify the page and trigger further updates.

Conclusion
The browser converts website resources into a visual webpage through network communication, HTML and CSS processing, JavaScript execution, and rendering.
